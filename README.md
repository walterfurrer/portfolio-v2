## Walter Furrer Portfolio

This repository contains the homepage for Walter Furrer's portfolio, built with Next.js, React, and Tailwind CSS.

### Setup

Requirements: Node.js 20.9 or newer and pnpm 11.22.0.

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Checks and production build

```bash
pnpm lint
pnpm typecheck
pnpm format:check
pnpm build
pnpm start
```
